SUPPORT

困ったときは

v2.1.0対応 · 最終更新日：2026年9月26日

困っていることを選んでください。3つのゲームの操作、カメラ、記録を順に確認できます。

いま困っていること

全身を認識できない 距離・明るさ・映る人数を確認 ドッグドロップが反応しない 足元・中央姿勢・動き方を確認 ドッグトレイルの調整・操作で困った しゃがむ範囲・犬の高さを確認 コグニドロップで答えられない 左右ステップ・得点・記録を確認 カメラを許可できない iPhone / iPadの設定を確認

ゲーム内容や基本操作を知りたい方へ ゲーム別の遊び方を見る

認識しやすい準備

どのゲームも最初はLevel 1から。ドッグドロップとコグニドロップは1分、ドッグトレイルは約1分のコースで、次の順番に環境を整えます。

基本の準備を確認する
  1. 左右へ一歩動き、無理なくしゃがめる広さを確保します。
  2. 画面を自分へ向け、端末を腰くらいの高さの倒れにくい場所へ置きます。
  3. 周囲の物・コード・段差、床の滑りやすさ、体調を確認します。
  4. 姿勢調整・スクワット調整へ進んだら約1.5m離れ、頭から足元までカメラに入れます。
  5. カメラに入るのはプレイヤー1人だけにします。
  6. 室内を明るくし、強い逆光を避けます。

準備できた状態正面を向いた全身がカメラに映り、数秒安定して立てます。ドッグドロップとコグニドロップは人型の枠、ドッグトレイルは撮影枠と動きの案内を確認します。

プレイを始める前に

痛み、めまい、強い疲れ、体調不良があるときはプレイしないでください。プレイ中に異常を感じた場合も、すぐに中止してください。

カメラを使えない

カメラの許可状態と、アプリの再起動を順に確認します。

カメラの許可を拒否した／変更したい

症状カメラの許可が必要という案内が表示され、姿勢調整へ進めない。

主な原因初回確認で許可しなかった、または後から設定を変更した。

  1. iPhone／iPadの「設定」を開きます。
  2. 「プライバシーとセキュリティ」→「カメラ」を開きます。
  3. 一覧にある「わんムーブ」をオンにします。旧バージョンでは「DogDrop」と表示されます。
  4. わんムーブをいったん終了し、もう一度起動します。

正常な状態準備画面の後、カメラ映像が表示され、姿勢調整またはスクワット調整を行えます。

カメラ映像が表示されない／姿勢調整が進まない

症状姿勢調整で映像が表示されない、または全身を枠へ合わせる画面から進まない。

主な原因権限が反映されていない、カメラの開始に失敗した、全身が認識範囲に入っていない。

  1. わんムーブのカメラ許可がオンになっていることを確認します。
  2. カメラを使用しているほかのアプリを終了します。
  3. わんムーブを終了して再起動します。
  4. 改善しない場合はiPhone／iPadを再起動します。
  5. 前面カメラを覆っているケースや物がないか確認します。

正常な状態ドッグドロップとコグニドロップは全身を認識すると次の案内へ進みます。ドッグトレイルは立つ・しゃがむ・立つの調整が進みます。

カメラ映像を表示するのは姿勢調整・スクワット調整中だけです。カメラ映像と身体の骨格座標は保存・送信しません。

全身を認識できない

頭、膝、足元の映り方と、カメラに入る人数を優先して確認します。

認識されない／プレイ中に認識が外れる

症状全身を枠へ合わせる案内から進まない、またはプレイが自動的に一時停止する。

主な原因頭・膝・足元が画面外、複数人が映る、逆光や暗さ、身体の一部が物に隠れている。

  1. 端末から約1.5m離れ、頭から足元まで入る位置に立ちます。
  2. プレイヤー以外の人がカメラに入らないようにします。
  3. 特に両膝と足元が隠れていないことを確認します。
  4. 照明をつけ、全身が明るく映る環境にします。
  5. 正面を向いて数秒静止します。ドッグトレイルの調整では、画面の案内に合わせて腕を胸の前で組みます。
  6. 窓や強い照明を背にしないよう、端末または身体の向きを変えます。

正常な状態姿勢調整が完了し、認識が戻ると操作練習またはゲームが再開します。

ドッグドロップ：ステップ・スクワットが反応しない

動作後に中央姿勢へ戻ることと、膝・足元が映っていることが大切です。

サイドステップが反応しない

症状左右へ動いても犬が移動しない。

主な原因動きが小さい、中央へ戻る前に次の動作をしている、膝や足元が見えていない。

  1. 正面を向き、両膝と足元がカメラに入っていることを確認します。
  2. 動かしたい方向の脚を横へ一歩スライドします。
  3. 一歩動いた後は、脚を中央へ戻します。
  4. 中央で姿勢を安定させてから次の一歩を行います。

正常な状態一歩ごとに犬が対応する方向へ1レーン移動します。

スクワットが反応しない

症状しゃがんでも犬が素早く降下しない。

主な原因上下動が小さい、身体が横を向いている、膝が画面外、立った姿勢へ戻っていない。

  1. 前面カメラへ正面を向き、頭から足元まで入る位置に立ちます。
  2. 両腕を無理のない範囲で前へ伸ばします。
  3. 椅子に座るように、腰をゆっくり下げます。
  4. 犬が降下したら、立った姿勢へ戻ってから次の動作を行います。

正常な状態一回のスクワットで犬が素早く降下し、立ち上がると次の入力を受け付けます。

意図しない動きが入る／同じ動作が続く

症状動いていない方向へ犬が移動する、入力が一度で止まらない。

主な原因基準姿勢が安定する前に動いた、動作後に中央へ戻っていない、端末や身体が揺れている。

  1. 両足を中央に戻し、正面を向いて数秒静止します。
  2. 一動作ずつ行い、毎回中央姿勢へ戻ります。
  3. 端末が揺れない場所へ置き直します。
  4. ほかの人や動く物がカメラへ入らないようにします。

正常な状態横への一歩に対して1レーン移動します。中央姿勢では意図しない横移動やスクワット入力が入りません（通常の落下は続きます）。

ドッグトレイル：スクワット調整・犬の高さ

ドッグドロップの「素早く降下」と異なり、ドッグトレイルではしゃがむ深さに合わせて犬の高さが連続して変わります。

スクワット調整が進まない

症状「自然に立とう」「ゆっくりしゃがもう」などの案内から進まない。

主な原因腰が画面外・隠れている、動き続けている、端末を動かして基準が変わった。

  1. 明るい場所で正面を向き、頭から足元、左右の腰が映る位置に立ちます。
  2. 腕を胸の前で組み、自然な立位で案内が進むまで静止します。
  3. ゆっくり浅くしゃがみ、「そのまま」が出たら楽に保てる高さで静止します。
  4. 最後にゆっくり立ち上がり、自然な立位で待ちます。
  5. 端末の位置を変えた場合や、調整が合わない場合は「コース選択へ戻る」からやり直します。

正常な状態3つの案内が順に進み、立位に戻ると準備が完了します。

見本と同じ深さに合わせたり、反応させるために無理に深くしゃがんだりする必要はありません。

犬の高さが合わない／路上率が低い
  1. しゃがむと犬が下へ、立ち上がると上へ動くことを確認します。
  2. 犬の足先ではなく、胴体の丸い判定点を道の中へ合わせます。
  3. 右側に見える道を見て、ゆっくり動き始めます。まずはLevel 1で試してください。
  4. 立っても犬が上へ戻らないなど、調整が合わない場合はコース選択へ戻り、スクワット調整をやり直します。

正常な状態調整した無理のない範囲の中で犬を上下に動かせます。

路上率は上下動の区間で道に乗っていた時間の割合です。立位休憩や追跡停止は採点対象外。銅60％・銀75％・金90％以上が目安です。

コースや難易度はどう違う？

Level 1〜3にそれぞれ6パターンがあります。Levelが上がると道幅が狭くなり、上下動のペースにも変化が加わります。1コースの上下動は6回です。

Level 3には調整した範囲の下端まで使う動きが1回あります。調整した範囲を超えて深くしゃがむ必要はありません。負担を感じたら中止し、次回は無理のない範囲とLevelを選んでください。

ドッグトレイルの遊び方へ

コグニドロップ：左右ステップ・得点・記録

コグニドロップは、左右ステップだけで答えます。スクワットや回転は答えの操作になりません。

答えのレーンへ移動できない／意図と違う答えになる

症状一歩動いても犬が移動しない、または意図した側と違うレーンへ着地する。

主な原因足を戻す前に次の動作をした、膝や足元が見えていない、中央姿勢が安定していない。

  1. 正面を向き、頭から足元までカメラに入っていることを確認します。
  2. 正しい答えがある側へ、片脚を横に一歩出します。
  3. 犬が1レーン移動したら、出した足を中央へ戻します。足を戻しても犬はそのレーンに残ります。
  4. 次の問題は、中央姿勢が安定してから一歩動きます。
  5. 設定画面の「遊び方を見る」から、必要に応じて「ステップを試す」を選びます。

正常な状態左右への一歩ごとに犬が対応する側へ1レーン移動し、中央姿勢では横移動しません。

得点・未回答・平均回答タイムを確認したい
  • 正しい答えのレーンへ着地：正解＋1点
  • 誤った答えのレーンへ着地：誤答−1点
  • 中央レーンのまま着地：未回答−1点

平均回答タイムは、問題が出てから、着地前に最終的に正解のレーンへ入るまでの時間を正解した問題だけで平均したゲーム内の指標です。移動にかかる時間も含み、医学的な反応時間を示すものではありません。

プレイ終了後の「結果／得点ベスト／タイムベスト」で確認します。得点と平均回答タイムは別々のベスト3です。タイムベストは、同じ条件で全問正解したプレイだけが対象です。

コグニドロップの遊び方へ

ゲーム・音・対応環境

ゲームが進まないときは、認識状態と端末側の設定を確認します。

ゲームが一時停止したまま／進行しない

症状一時停止または追跡停止の案内が表示され、タイマーが進まない。

主な原因手動で停止した、または全身認識が外れて安全のため自動停止した。

  1. 一時停止メニューが表示されている場合は「再開」を選びます。
  2. 認識の案内が表示されている場合は、全身を入れて中央姿勢で数秒静止します。
  3. ドッグトレイルでは認識が安定した後のカウントダウンを待ちます。停止中は道・コース時間・採点も止まります。
  4. 復帰しない場合はタイトルへ戻り、ゲームとLevel・コースを選び直します。
  5. 同じ状態が続く場合はわんムーブを終了して再起動します。

正常な状態案内が消え、タイマーと犬の操作が再開します。

音が出ない

症状BGM、犬の鳴き声、ゴール時の効果音が聞こえない。

主な原因メディア音量が小さい、Bluetooth機器へ出力されている、音声処理が一時的に停止している。

  1. 端末の音量ボタンでメディア音量を上げます。
  2. イヤホンやスピーカーなど、Bluetoothの接続先を確認します。
  3. わんムーブを終了して再起動します。
  4. ほかのアプリで端末から音が出るか確認します。

正常な状態ゲームごとのBGM、ドッグドロップで犬をそろえたときとコグニドロップで正解したときの鳴き声、コグニドロップで誤答したときの低い音、完走時の効果音が再生されます。ボタン操作の効果音はありません。

端末またはOSが対応しているか分からない
  1. App Storeのわんムーブ（旧DogDrop）ページで「互換性」を確認します。
  2. 「設定」→「一般」→「情報」で、機種名とOSバージョンを確認します。
  3. 利用可能なOSアップデートがある場合は、内容を確認して更新を検討します。

正常な状態App Storeからインストールまたは更新でき、前面カメラを使った姿勢調整へ進めます。

記録を確認したい

タイトルの「プレイ記録」から、ドッグドロップ・ドッグトレイル・コグニドロップの回数と時間を日・週・月・年ごとに確認できます。記録は端末内に保存されます。

プレイ履歴や記録が見つからない

症状完了したプレイの記録が表示されない。

主な原因途中でプレイを終えた、別の期間・ゲームを見ている、保存されていない過去の記録を探している。

  1. ドッグドロップとコグニドロップはタイマー終了まで、ドッグトレイルはゴールまでプレイし、結果画面を確認します。
  2. タイトルの「プレイ記録」で、日・週・月・年と対象期間を確認します。
  3. ゲーム別の内訳を確認します。コグニドロップの得点・タイムのベスト3は、プレイ終了後の結果画面で確認します。

正常な状態完了したプレイが端末内の集計へ反映されます。

準備・追跡停止・復帰待機はプレイ時間に含みません。ドッグトレイルの記録時間はコース中の立位休憩を含みますが、開始待ちとゴール演出を除くため、「約1分」という案内より短くなります。過去の記録が保存されていない期間は再現できません。

再インストール後に記録が消えた

ゲーム履歴は端末内だけに保存され、アカウントやクラウドへ同期しません。アプリを削除すると、履歴も削除される場合があります。

現在、削除済みの記録をアプリ内で復元する機能はありません。

正常な状態再インストール後のプレイから、新しい記録が保存されます。

安全性とプライバシー

安全に遊ぶために

  • 左右と後方に、物や人へぶつからない空間を確保してください。
  • 端末は倒れたり滑ったりしない場所へ置いてください。
  • 無理に深くしゃがんだり、大きく動いたりしないでください。
  • 年齢や体力に合わせて、無理のない範囲で楽しんでください。

データの取扱い

  • カメラ映像と身体の骨格座標は端末上で処理し、保存・送信しません。
  • ゲーム履歴は端末内へ保存し、クラウドへ同期しません。
  • 利用状況データは、同意した場合に限り分析のため送信します。
プライバシーの詳細を見る

新しいプライバシー設定は準備中です。2026年9月26日時点の配信版2.1.0には含まれていません。下記では現在の方法と、対応版で追加予定の操作を分けて案内します。

利用状況データの共有を止めたい

現在の配信版：初回画面で「送信しない」を選択できます。同意済みの場合は再インストールが必要ですが、端末内の記録が失われる場合があります。先に現在の停止方法と注意点をご確認ください。

追加予定の操作：タイトル →「プライバシー設定」→「共有しない」。新しい解析を停止し、未送信分を破棄します。すでに届いたデータの削除は別に依頼します。

対応版での表示「共有：オフ」と表示され、再起動後もオフが維持されます。共有しなくてもゲームとプレイ記録を利用できます。

送信済みの解析データを削除したい

現在の配信版：プライバシーページの窓口へ「わんムーブ データ削除依頼」としてご連絡ください。アプリを削除するだけでは送信済みデータは削除されません。

追加予定の操作：「プライバシー設定」→「解析データの削除を依頼」→「オフにして削除を依頼」。共有をオフにして、このインストールに紐付くデータの削除を依頼します。別端末や再インストール前のデータまで対象になるとは限りません。

「Unityが削除依頼を受信しました」は受付を示します。サーバー側の削除完了を示す表示ではありません。進捗は上記窓口へお問い合わせください。

対応版で「削除依頼を保存しました」のまま進まないとき

以下は追加予定の設定画面の案内です。依頼は端末に保存され、通信できる状態で再試行します。

  1. 通信できることを確認し、アプリを開いてください。
  2. エラーと「再試行」が表示されている場合は、「再試行」を選んでください。
  3. 依頼の送信が終わるまで、アプリを削除しないでください。

依頼の送信が終わるまでは共有を再開できません。オンラインでも状態が変わらない場合は、お問い合わせ窓口へ表示内容をお知らせください。

共有停止や削除依頼でプレイ記録も消えますか？

追加予定の設定画面で行う共有停止や解析データの削除依頼では、端末内のプレイ記録・自己ベスト・言語設定は残ります。

アプリ自体を削除すると記録が失われる場合があり、クラウドから復元する機能はありません。
